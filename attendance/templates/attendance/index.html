How to point an ADMS device at this server
  1. On the device: Menu → Comm. → Cloud Server Setting (ADMS).
  2. Server address: this server's public IP or domain (not 127.0.0.1). Port: {{ adms_port }} (the port this app is served on).
  3. Within a minute the device shows up in the yellow Unregistered device box above: click Register.
